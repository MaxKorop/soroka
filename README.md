# Сорока 🐦

Приватний Telegram-бот для двох: «сорока на хвості принесла».
Python 3.12 · aiogram 3 (long polling) · yt-dlp + ffmpeg · Neon Postgres.

## Що вміє

- **Відео**: кидаєш посилання на TikTok / Instagram Reels / YouTube (відео та Shorts) — бот завантажує і постить нативне відео в тему «відео».
  Якщо файл > 50 МБ — спочатку пробує нижчу якість, потім відповідає посиланням.
  Якщо завантаження впало — відповідає в образі, без мовчання.
- **Фільми**: `/movie_add Назва | Жанр`, `/movies` (згруповано за жанром, «хочемо» / «подивились»), `/movie_done <номер>`.
- **Продукти та меню** (тимчасово): `/need`, `/needed`, `/got`, `/cook`, `/menu`, `/cooked`.

## Налаштування

1. Створи бота в @BotFather, вимкни privacy mode (`/setprivacy` → Disable), щоб бачити всі повідомлення в групі, і додай його адміном (для `DELETE_ORIGINAL` потрібне право видаляти повідомлення).
2. Дізнайся `GROUP_ID` та `VIDEOS_TOPIC_ID` (напр. перешли повідомлення з теми боту @RawDataBot; `message_thread_id` — це id теми).
3. `cp .env.example .env` і заповни. Рядок підключення Neon — тільки в `.env`.
4. Для Instagram: експортуй `cookies.txt` (Netscape-формат) з **додаткового** акаунта в корінь проєкту. Якщо не потрібно — `touch cookies.txt`.

## Запуск

Локально:

```bash
python3.12 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt   # потрібен ffmpeg в PATH
python -m soroka
```

На VM (Docker):

```bash
docker compose up -d --build
```

Таблиці створюються автоматично при старті (`soroka/schema.sql`).

## Підтримка

yt-dlp ламається разом з платформами — оновлюй регулярно:

```bash
docker compose build --no-cache && docker compose up -d
```

## Прийняті рішення за замовчуванням (відкриті питання)

| Питання | Зараз |
|---|---|
| Видаляти оригінальне повідомлення? | Ні, перемикається `DELETE_ORIGINAL=true` |
| Завелике відео | Нижча якість → інакше посилання |
| Помилка / приватне посилання | Коротка відповідь у характері |
| Метадані фільмів | Жанр вручну; TMDB — пізніше |
| Продукти в спільній БД з іншим застосунком | Окремі таблиці `groceries`, `meals`; легко винести |
